# Museum of Minimalism — демо-сайт (Flask + JS + PHP)

Главная страница — точная копия вёрстки/стилей референсного сайта
[milamiss/Online-museum](https://milamiss.github.io/Online-museum/)
(Bootstrap 4, шрифты Roboto/Open Sans). Поверх неё достроен многошаговый
флоу бронирования билетов (карточка выставки → планирование визита →
бронь → оплата → подтверждение) по мотивам присланного Figma-макета,
оформленный в той же цветовой/шрифтовой системе.

## Стек и распределение ролей

- **Python 3 + Flask** — сервер, маршруты, вся бизнес-логика бронирования:
  сессии, расчёт цены, промокоды, таймер резерва 30 минут, валидация формы
  оплаты (`app.py`, данные — в `data.py`).
- **JavaScript** (без сборки, vanilla) — вся интерактивность на клиенте:
  бургер-меню, оверлей поиска, выбор времени/типа взаимодействия,
  +/- количества билетов и промокод по AJAX, обратный отсчёт таймера,
  отправка формы подписки на рассылку.
- **PHP** — обрабатывает единственную реальную форму оригинального сайта:
  подписку на рассылку (`php/subscribe.php`). Валидирует email, отсекает
  повторную подписку и дописывает её в `php/subscribers.csv`. Flask не
  запускает отдельный PHP-сервер — он вызывает скрипт как подпроцесс
  (`php php/subscribe.php`) на каждый POST `/api/subscribe` и пробрасывает
  его JSON-ответ в браузер.

## Структура стилей

- `static/site/css/style.css` — CSS референсного сайта, скопирован как
  есть (с точечным скоупингом двух-трёх изначально global-селекторов,
  которые на многостраничном сайте иначе задевали бы другие страницы).
- `static/site/img/` — оригинальные SVG/PNG референсного сайта.
- `static/css/interactive.css` — стили выпадающего меню и оверлея поиска
  (общие для всех страниц; в оригинале эти кнопки были декоративными).
- `static/css/flow.css` — стили страниц бронирования, в тех же цветах/
  шрифтах, что и клонированная главная.

## Как запустить локально

```bash
cd museum-of-minimalism
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Открыть в браузере: **http://localhost:5000**

Чтобы заработала форма подписки на рассылку, в PATH должен быть доступен
`php` (проверить: `php --version`). Если PHP не установлен — форма
покажет понятную ошибку вместо зависания; остальной сайт работает как
обычно.

## Пользовательский путь

1. **/** — главная страница (точная копия оригинала + форма подписки).
2. **/exhibition/sequence** — карточка выставки Ричарда Серра, «Plan your
   visit»: выбор времени и типа взаимодействия (360° / XR / Guide).
3. **/reservation** — выбор типа и количества билетов + способ связи.
4. **/checkout** — итоговый заказ, промокод (`MINIMAL10` -10%,
   `SERRA20` -20%), оплата, таймер резерва.
5. **/done** — подтверждение и рекомендации похожих выставок.

## Деплой в интернет (Render)

`gunicorn` в `requirements.txt`, `Procfile`, `render.yaml`, секретный ключ
и debug-режим читаются из переменных окружения. Форма подписки хранит
email в `subscribers.csv` через чистый Python (`app.py`), без внешних
зависимостей — работает на Render "из коробки".

1. Загрузите содержимое этой папки в репозиторий на GitHub.
2. На [render.com](https://render.com) → **New +** → **Blueprint** →
   выберите репозиторий; Render прочитает `render.yaml`.
3. Сайт будет доступен по адресу вида
   `https://museum-of-minimalism.onrender.com`.
